
# Career Advisor Expert System

A rule-based expert system written in Python that recommends careers based on a user's interests and skills.

## Features
- Asks yes/no questions about the user's interests and strengths
- Uses forward chaining over 20 expert rules
- Explains the reason behind each recommended career

## Concepts Used
- Knowledge base and rule-based reasoning
- Forward chaining inference

## Built With
- Python
